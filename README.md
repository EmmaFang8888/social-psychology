# 社会心理学课程知识库

方霞负责的教学部分。前7次授课，第8次为期中测验与整合，每次3个45分钟课时，共24课时。

包含核心知识、按课时分层的研究与阅读、中文导读、练习参考思路和可复制的AI阅读提示词。英文文献题名保留原文，引用与访问入口逐项列出。

## 发布

在本仓库 Settings → Pages 中，选择 Deploy from a branch，分支 main，目录 /(root)，保存。

index.html 是完整独立网页，内嵌样式、课程及文献数据，不依赖ChatGPT服务或账号。

## 阅读说明

每次优先选读1篇重点文献的指定段落，其余按课时与兴趣拓展。外部文献全文的访问权限由原出版社或作者网站决定。中文导读为教学整理，不替代原文。

本页不提供在线AI聊天；AI辅助部分为可复制的阅读反馈提示词。
